# 第 1 阶段前端开发文档｜投递页 + 后台页（Next.js）

> 配套：前端技术适配声明、`../../docs/阶段文档-step5.md`

## 1. 本阶段目标
用 Next.js 重做投递页与后台页，打通真实后端全链路，替换现有 Jinja2 两页。

## 2. 范围
- **包含**：`/s/[token]` 4 步投稿向导、`/admin` 登录+建活动+总览+明细筛选+CSV 导出+简报+智能问答、统一 API 层、设计 token、响应式。
- **不包含**：正式视觉设计稿落地、Playwright E2E、多终端、流式/长任务、多管理员。

## 3. 用户流程
1. 管理员登录后台 → 创建活动 → 复制投递链接。
2. 艺术家打开 `/s/[token]` → ①个人资料 ②上传简历 ③作品资料（可多件）④确认提交。
3. 提交后回显 AI 核验报告。
4. 管理员查看总览/明细、筛选、导出 CSV、生成简报、智能问答。

## 5. 接口契约（经 Next.js 同源代理 `/api/*`、`/files/*` → `http://127.0.0.1:8000`）
- `GET /api/v1/campaigns/{token}`；`POST /api/v1/campaigns/{token}/submissions`（multipart）。
- 管理员：`POST /admin/login|logout`、`GET|POST /admin/campaigns`、`GET /admin/campaigns/{id}/overview|works|export.csv`、`POST /admin/campaigns/{id}/brief|query`、`POST /admin/run_sql`。
- 错误：统一 `{detail: string}`；超时/网络错误前端归一化为可读提示。
- Mock 与真实接口：直接对接真实后端（无 Mock）。

## 6. 实现方案
- 路由：`app/s/[token]/page.tsx`、`app/admin/page.tsx`、`app/page.tsx`（重定向 /admin）。
- 组件：`components/ui`（Button/Input/Field/Card/Alert/Spinner）+ 页面内业务组件。
- 状态来源：后端（活动、投稿、统计、简报）；前端仅临时状态（表单值、步骤、选中活动）。
- 流式/轮询：无。
- 响应式：移动端表格改卡片/受控滚动，侧栏无（单列布局）。
- 安全隐私：密钥不进前端；`HttpOnly` Cookie 会话（同源代理）；图片经 `/files/*` 只读服务。

## 7. 验收标准
- 390/768/1280/1440 四档宽度核心流程可用。
- `npm run lint`、`npm run typecheck`、`npm run test`、`npm run build` 全通过。
